# Reuniones

Índice de transcripciones y documentos de trabajo de las reuniones del proyecto.

## Convención

- Una carpeta por reunión: AAAA-MM-DD_HHMM_tema-en-kebab-case.
- La fecha y hora se toman del registro de la reunión o, si no se conocen, del nombre del audio y se indican como aproximadas.
- Dentro de cada carpeta, usar nombres con fecha, hora, tipo y tema: AAAA-MM-DD_HHMM_tipo_tema.md; por ejemplo, transcripcion_tema o plan_tema.
- Guardar en el repositorio los documentos Markdown revisables. No copiar los audios; los archivos .m4a están excluidos de Git.
